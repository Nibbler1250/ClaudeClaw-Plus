## Evidence plan

The integration suite drives `runOnceOnPty` with `isolation: untrusted`, using a temporary HOME/config on GitHub Actions. The production capability gate is opened only within the test and restored afterwards. Nothing runs against a developer's real Claude configuration. The workflow alone supplies authentication through its existing secret-scoped environment; no test reads, copies or logs a credential.

| Property | Production control | Baseline / control-removed twin |
| --- | --- | --- |
| Tools | `--tools ""` | injection cannot create a marker or record tool_use / tools enabled with permission setup must create the marker |
| MCP | `--strict-mcp-config`, no config supplied | user-configured stub never starts / dropping strict mode starts it |
| Settings/hooks | `--setting-sources ""` | hook markers absent / dropping the source restriction writes one |
| Memory | source restriction, empty cwd | user CLAUDE.md canary absent / dropping source restriction reveals it |
| Commands, cwd, transcript | `--disable-slash-commands`, slash-input guard, fresh cwd, finally cleanup | command canary absent and temp artifacts removed / removing command controls exposes canary, bypassing transcript cleanup leaves JSONL |
| Environment | caller's print environment policy compared against real PTY child | irrelevant fake secret absent / deliberately admitting it makes the same check fail |

The probe code asserts the expected result for each direction. A baseline failure or a twin that cannot demonstrate leakage blocks rollout. Logs expose only canary booleans and sanitized status, never raw output or environments.

## Shared argv and print-only compensation

Both engines consume the single `UNTRUSTED_CLAUDE_ARGS` constant: `--tools "" --strict-mcp-config --setting-sources "" --no-session-persistence --disable-slash-commands`. The test captures actual supervisor spawn options and prints the exact built argv; a unit parity test catches missing flags/values. No flags are inferred from documentation alone.

Interactive transcript persistence must be treated as enabled even with the shared print-only flag. After the one-shot PTY is fully retired, cleanup removes the unique project's transcript directory under `CLAUDE_CONFIG_DIR` (or HOME/.claude), then removes the temporary cwd. A separate project directory is preserved. A control-removed twin disables that cleanup and must leave a real JSONL artifact.
